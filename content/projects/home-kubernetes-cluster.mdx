I use this repository to track the Kubernetes cluster I run at home.

The cluster runs on NixOS machines with `k3s` as the Kubernetes distribution, so the base system and the cluster config both stay reproducible.

I use Flux CD to manage continuous delivery. Changes land in Git first, then Flux applies them to the cluster, which keeps deployment and rollback simple.

The repository collects the machine config, cluster manifests, and operating notes in one place so I can rebuild the cluster and keep it maintainable.
